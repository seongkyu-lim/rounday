# Rounday MVP Release Notes

## Scope

Rounday is a local-first circular daily planner for building, editing, analyzing, sharing, and exporting 24-hour routines.

## Included

- Circular 24-hour schedule editor
- Direct clock interaction
- Multiple day profiles
- Local account session state
- Local-first persistence schema
- Schedule insights
- Share links, SVG export, print layout, JSON import/export
- Custom templates
- Regression tests for time calculations
- CI workflow for launch validation

## Verification

- `npm test`
- `node --check app.js`
